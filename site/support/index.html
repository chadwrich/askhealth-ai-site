For Technical Issues

For technical support, please visit our GitHub repository issues page. This helps us track and resolve problems efficiently.

What to Include

When reporting an issue, please provide:

  • Description of the problem
  • Steps to reproduce the issue
  • Your device model and iOS version
  • App version (found in Settings)

Response Time

We aim to respond to support requests within 2-3 business days. Critical issues are prioritized.
